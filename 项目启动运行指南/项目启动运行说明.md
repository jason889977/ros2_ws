# 项目启动运行说明

适用范围：日常启动 Basler 相机、二维码识别和 AprilTag 检测。三个节点由同一个 `basler_camera` Docker 容器统一运行。

详细集成与调用文档（推荐先看）：
- `./工控机ROS2集成与调用超详细指南.md`

## 1. 启动前检查

确认相机已上电、网线已连接，并进入工作区：

```bash
cd /home/ubuntu/ros2_ws
```

首次部署或容器不存在时，先执行一次：

```bash
cp deploy/basler_camera/.env.example deploy/basler_camera/.env
docker compose --env-file deploy/basler_camera/.env \
  -f deploy/basler_camera/docker-compose.yml up -d
```

## 2. 日常启动

```bash
sudo -n docker restart basler_camera
sudo -n docker inspect --format '{{.State.Status}} {{.State.Health.Status}}' basler_camera
```

第二条命令应最终显示：

```text
running healthy
```

若刚重启仍显示 `starting`，等待约 30 秒后重复执行第二条命令。

## 3. 确认相机图像正常

```bash
sudo -n docker exec basler_camera bash -lc \
  'source /opt/ros/humble/setup.bash && source /opt/ros2_ws/install/setup.bash && \
   timeout 8 ros2 topic hz /my_camera/pylon_ros2_camera_node/image_raw'
```

能显示图像话题频率，即相机图像链路正常。

## 4. Keyence SR 扫码器

Keyence SR 节点由 `basler_camera` 容器随项目一起启动，默认连接扫码器 `172.31.0.91:9004`，无需在宿主机单独启动节点。

先在一个终端持续监听扫码结果：

```bash
sudo -n docker exec basler_camera bash -lc \
  'source /opt/ros/humble/setup.bash && source /opt/ros2_ws/install/setup.bash && \
   ros2 topic echo /my_camera/scanner/barcode'
```

在另一个终端触发一次扫码：

```bash
sudo -n docker exec basler_camera bash -lc \
  'source /opt/ros/humble/setup.bash && source /opt/ros2_ws/install/setup.bash && \
   ros2 service call /my_camera/scanner/trigger std_srvs/srv/Trigger {}'
```

服务返回 `success: true` 且 `/my_camera/scanner/barcode` 输出字符串，即扫码正常。

如需更换扫码器地址，修改下列命令中的 IP、端口和重连间隔后执行；容器会按新参数重建：

```bash
cd /home/ubuntu/ros2_ws
SCANNER_IP=172.31.0.92 SCANNER_PORT=9004 RECONNECT_INTERVAL_S=3.0 \
sudo -n docker compose -f deploy/basler_camera/docker-compose.yml \
  up -d --force-recreate
```

## 5. 查看视觉识别结果

### 二维码

将二维码放入相机视野后执行：

```bash
sudo -n docker exec basler_camera bash -lc \
  'source /opt/ros/humble/setup.bash && source /opt/ros2_ws/install/setup.bash && \
   ros2 topic echo /my_camera/qr/decoded_info --once'
```

输出二维码文本即表示识别正常。

### AprilTag

将 `tag36h11`、ID 为 `3` 的标签放入相机视野后执行：

```bash
sudo -n docker exec basler_camera bash -lc \
  'source /opt/ros/humble/setup.bash && source /opt/ros2_ws/install/setup.bash && \
   ros2 topic echo /my_camera/apriltag/pose --once'
```

有位姿输出即表示 AprilTag 检测正常。需要查看完整检测信息时：

```bash
sudo -n docker exec basler_camera bash -lc \
  'source /opt/ros/humble/setup.bash && source /opt/ros2_ws/install/setup.bash && \
   ros2 topic echo /my_camera/detections --once'
```

## 6. 打开图像画面（可选）

```bash
/home/ubuntu/ros2_ws/scripts/open_camera_rviz.sh
```

## 7. 停止项目

```bash
sudo -n docker stop basler_camera
```

## 注意事项

- 日常运行只管理 `basler_camera` 容器；不要在宿主机另行启动 `pylon_ros2_camera_wrapper`，否则可能抢占相机。
- Keyence SR 无法扫码时，先确认扫码器已上电且主机网络可访问其配置的 IP 与端口。
- Docker 命令中的 `sudo -n` 需要当前用户具备免密 sudo；若命令提示权限不足，请使用有权限的账户执行。
