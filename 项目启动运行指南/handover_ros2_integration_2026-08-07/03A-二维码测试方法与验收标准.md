# 二维码测试方法与验收标准

## 测试基线

执行本验收前，确认 `deploy/basler_camera/.env` 中 `ENABLE_QRCODE=true`，否则二维码节点不会启动。

- 相机：`basler_camera` 容器
- 图像：Mono8、`1294x970`、`2x2 binning`
- 输入：`/my_camera/pylon_ros2_camera_node/image_raw`、`/my_camera/pylon_ros2_camera_node/camera_info`
- 算法：`prefer_wechat_qr:=true`

## 图像与识别

```bash
ros2 topic info -v /my_camera/pylon_ros2_camera_node/image_raw
ros2 topic hz /my_camera/pylon_ros2_camera_node/image_raw
ros2 topic echo /my_camera/qr/decoded_info --once
ros2 topic echo /my_camera/wechat_qr_node/qr_pose --once
```

必须实际收到相机图像；二维码进入视野后应输出文本。启用 `use_camera_info` 时应输出带相机 frame 的位姿。

## 错误守门

```bash
sudo -n docker logs --since 5m basler_camera 2>&1 | \
  grep -Ei '3774873620|incompletely grabbed|Grab was not successful' || true
```

不得出现持续重复的抓取错误。测试记录应包含图像到达率、识别结果和错误扫描结果。
