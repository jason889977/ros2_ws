# 快速启动指南

适用范围：Basler 工业相机、WeChatQR 二维码识别与 6D 位姿解算、AprilTag 检测与位姿解算、Keyence 扫码器的日常启动、验证与停止。所有视觉链路已统一整合在 `basler_camera` Docker 容器中或支持本地一键 Launch。

详细部署与运维说明请参阅 [项目启动运行指南/工控机集成与运维指南.md](项目启动运行指南/工控机集成与运维指南.md) 与 [项目启动运行指南/部署与开发操作手册.md](项目启动运行指南/部署与开发操作手册.md)。

---

## 1. 启动前准备

确认硬件连接正常（Basler 相机与 Keyence 扫码器已通电且网线接入工控机对应网口），进入项目工作区：

```bash
cd /home/ubuntu/ros2_ws
```

如果是首次部署或配置有变更：

```bash
cp deploy/basler_camera/.env.example deploy/basler_camera/.env
# 根据产线实际情况编辑 deploy/basler_camera/.env (如相机 IP/ID、扫码器 IP、算法开关等)
```

---

## 2. 生产环境启动 (Docker Compose)

### 2.1 启动容器

```bash
docker compose --env-file deploy/basler_camera/.env \
  -f deploy/basler_camera/docker-compose.yml up -d
```

### 2.2 查看运行状态与健康检查

```bash
# 查看容器状态与健康检查评级
docker inspect --format '{{.State.Status}} {{.State.Health.Status}}' basler_camera

# 查看实时运行日志
docker logs -f basler_camera --tail 30
```

正常运行时状态显示为 `running healthy`。健康检查探针自动验证每路相机的 `camera_info` 可达性、已启用组件节点存活情况，并确认 `vision/status` 综合等级不为 `ERROR` 或 `STALE`。若容器刚启动显示 `starting`，等待约 10~30 秒即可。

---

## 3. 验证相机与算法数据流

可直接在宿主机（需 `source /opt/ros/humble/setup.bash`）或通过 `docker exec` 进入容器验证输出话题（默认相机命名空间为 `my_camera`）：

### 3.1 相机图像流 (image_raw & camera_info)

```bash
docker exec basler_camera bash -lc \
  'source /opt/ros/humble/setup.bash && source /opt/ros2_ws/install/setup.bash && \
   ros2 topic hz /my_camera/pylon_ros2_camera_node/image_raw'
```

### 3.2 二维码识别与 6D 位姿 (QR Code)

> 注：需在 [deploy/basler_camera/.env](deploy/basler_camera/.env) 中配置 `ENABLE_QRCODE=true`。

```bash
# 监听二维码解码文本内容 (包含 deduplicate_window_s 去重)
docker exec basler_camera bash -lc \
  'source /opt/ros/humble/setup.bash && source /opt/ros2_ws/install/setup.bash && \
   ros2 topic echo /my_camera/qr/decoded_info --once'

# 监听二维码 6D 位姿 (solvePnP 解算，需有效相机内参)
docker exec basler_camera bash -lc \
  'source /opt/ros/humble/setup.bash && source /opt/ros2_ws/install/setup.bash && \
   ros2 topic echo /my_camera/qr/qr_pose --once'
```

### 3.3 AprilTag 位姿与变换 (AprilTag)

> 注：需在 [deploy/basler_camera/.env](deploy/basler_camera/.env) 中配置 `ENABLE_APRILTAG=true`。

```bash
# 查看解算后的 6D 位姿
docker exec basler_camera bash -lc \
  'source /opt/ros/humble/setup.bash && source /opt/ros2_ws/install/setup.bash && \
   ros2 topic echo /my_camera/apriltag/pose --once'

# 查看坐标系变换 (TransformStamped)
docker exec basler_camera bash -lc \
  'source /opt/ros/humble/setup.bash && source /opt/ros2_ws/install/setup.bash && \
   ros2 topic echo /my_camera/apriltag/transform --once'
```

### 3.4 Keyence 工业扫码器

> 注：需在 [deploy/basler_camera/.env](deploy/basler_camera/.env) 中配置 `ENABLE_KEYENCE=true`。

```bash
# 触发一次主动扫码 (发送 LON\r)
docker exec basler_camera bash -lc \
  'source /opt/ros/humble/setup.bash && source /opt/ros2_ws/install/setup.bash && \
   ros2 service call /my_camera/scanner/trigger std_srvs/srv/Trigger {}'

# 监听扫码结果发布
docker exec basler_camera bash -lc \
  'source /opt/ros/humble/setup.bash && source /opt/ros2_ws/install/setup.bash && \
   ros2 topic echo /my_camera/scanner/barcode --once'
```

### 3.5 视觉流水线综合状态 (VisionStatus)

```bash
docker exec basler_camera bash -lc \
  'source /opt/ros/humble/setup.bash && source /opt/ros2_ws/install/setup.bash && \
   ros2 topic echo /my_camera/vision/status --once'
```

## 6. 停止与重启容器

```bash
# 重启容器
docker compose --env-file deploy/basler_camera/.env \
  -f deploy/basler_camera/docker-compose.yml restart

# 停止容器
docker compose --env-file deploy/basler_camera/.env \
  -f deploy/basler_camera/docker-compose.yml down
```

## 注意事项

1. **资源互斥**：同一物理相机或同网口 IP 在同一时刻只能被单个进程/容器打开。请勿在宿主机和 Docker 容器内同时启动相机节点。
2. **双相机命名空间**：若部署双相机，第二路相机的 `CAMERA_ID_2`、`CAMERA_CONFIG_2` 与 `CAMERA_FRAME_2` 必须与第一路完全独立，以避免 TF 与话题冲突。
3. **网络与权限**：生产容器采用 `network_mode: host`。若 Docker 命令提示权限不足，请确保当前用户位于 `docker` 用户组或使用 `sudo` 执行。
