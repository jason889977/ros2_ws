# 快速启动指南

适用范围：日常启动 Basler 相机、二维码识别、AprilTag 检测和 Keyence 扫码。所有节点由同一个 `basler_camera` Docker 容器统一运行。

详细集成与运维说明请参阅 [工控机集成与运维指南.md](工控机集成与运维指南.md)。

## 1. 启动前检查

确认相机已上电、网线已连接，并进入工作区：

```bash
cd /home/ubuntu/ros2_ws
```

首次部署或容器不存在时：

```bash
cp deploy/basler_camera/.env.example deploy/basler_camera/.env
docker compose --env-file deploy/basler_camera/.env \
  -f deploy/basler_camera/docker-compose.yml up -d
```

## 2. 日常启动

```bash
sudo -n docker restart basler_camera
sudo -n docker inspect --format '{{.State.Status}} {{.State.Health.Status}}' basler_camera
```

最终应显示：

```text
running healthy
```

健康检查同时验证已启用模块的诊断状态；若汇总状态为 `ERROR` 或 `STALE`，容器不会被判定为 healthy。

刚重启时若显示 `starting`，等待约 30 秒后重新检查。

## 3. 确认相机图像

```bash
sudo -n docker exec basler_camera bash -lc \
  'source /opt/ros/humble/setup.bash && source /opt/ros2_ws/install/setup.bash && \
   timeout 8 ros2 topic hz /my_camera/pylon_ros2_camera_node/image_raw'
```

## 4. 验证视觉结果

以下二维码命令要求 `.env` 中 `ENABLE_QRCODE=true`；当前仓库示例 `.env` 默认关闭二维码，未启用时不会启动 `wechat_qr_node`。

### 二维码

```bash
sudo -n docker exec basler_camera bash -lc \
  'source /opt/ros/humble/setup.bash && source /opt/ros2_ws/install/setup.bash && \
   ros2 topic echo /my_camera/qr/decoded_info --once'
```

### AprilTag

将 `tag36h11`、ID 为 `3` 的标签放入视野后执行：

```bash
sudo -n docker exec basler_camera bash -lc \
  'source /opt/ros/humble/setup.bash && source /opt/ros2_ws/install/setup.bash && \
   ros2 topic echo /my_camera/apriltag/pose --once'
```

需要查看检测详情时：

```bash
sudo -n docker exec basler_camera bash -lc \
  'source /opt/ros/humble/setup.bash && source /opt/ros2_ws/install/setup.bash && \
   ros2 topic echo /my_camera/detections --once'
```

### Keyence

监听扫码结果：

```bash
sudo -n docker exec basler_camera bash -lc \
  'source /opt/ros/humble/setup.bash && source /opt/ros2_ws/install/setup.bash && \
   ros2 topic echo /my_camera/scanner/barcode'
```

触发一次扫码：

```bash
sudo -n docker exec basler_camera bash -lc \
  'source /opt/ros/humble/setup.bash && source /opt/ros2_ws/install/setup.bash && \
   ros2 service call /my_camera/scanner/trigger std_srvs/srv/Trigger {}'
```

## 5. 查看图像画面

```bash
/home/ubuntu/ros2_ws/scripts/open_camera_rviz.sh
```

双相机启用 AprilTag 时，必须为第二台相机配置独立的 `CAMERA_FRAME_2`，且不能与
`CAMERA_FRAME` 相同，否则两路标签 TF 可能冲突。

## 6. 标定入口

相机内参、AprilGrid 和手眼标定流程统一维护在 [CALIBRATION_AUTOMATION.md](CALIBRATION_AUTOMATION.md)。完成标定后，将生成的 CameraInfo 配置应用到相机 profile，再按本指南第 4 节验证图像和 AprilTag 位姿。

## 7. 停止项目

```bash
sudo -n docker stop basler_camera
```

## 注意事项

- 日常运行只管理 `basler_camera` 容器，不要在宿主机另行启动相机节点。
- Keyence 无法扫码时，先确认设备已上电且 IP/端口可达。
- Docker 命令中的 `sudo -n` 需要当前用户具备免密 sudo 权限。
