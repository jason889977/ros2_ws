适用对象：
- 需要将本项目集成到工控机并与机械臂运动控制、MoveIt 2、MES 调度等其他 ROS 2 业务节点协同运行的工程师。
- 负责现场视觉节点部署、联调与日常运维的值班与交付人员。

适用环境：
- 工作区路径：`/home/ubuntu/ros2_ws`
- 操作系统：Ubuntu 22.04 LTS (x86_64)
- ROS 版本：ROS 2 Humble

---

## 1. 核心目标与集成三大原则

在同一台工控机上，系统通常需要并行运行：
- **机器人系统**：机械臂运动控制驱动、轨迹规划（MoveIt 2 / FollowJointTrajectory）、任务状态机与抓取调度。
- **视觉感知系统**（本项目）：Basler 工业相机驱动、WeChatQR 二维码识别与 6D 位姿解算、AprilTag 姿态解算与 Keyence 工业扫码器。

为确保系统零冲突稳定运行，必须遵守以下三条原则：
1. **DDS 域 ID 必须完全一致**：所有参与通信的宿主机程序与 Docker 容器，其 `ROS_DOMAIN_ID` 必须统一（例如统一设为 `0`）。
2. **DDS 实现保持兼容**：推荐全部统一使用 `RMW_IMPLEMENTATION=rmw_fastrtps_cpp`。
3. **接口契约与命名空间规范**：本项目所有输出话题与服务均挂载于 `/{camera_id}/` 命名空间下（默认 `my_camera`），业务层请通过参数化配置对接，避免硬编码。

## 2. 节点架构与运行模式

### 2.1 生产运行模式（Docker 统一容器）

生产环境统一使用单个 `basler_camera` 容器，以 Host 网络模式运行。全功能启用时，每路流水线包含 6 个运行节点：

- **组件容器内进程 (`vision_container_<camera_id>`)**（C++ 零拷贝 Intra-Process 通信）：
  - `/{camera_id}/pylon_ros2_camera_node`：Basler 相机采集与参数控制
  - `/{camera_id}/apriltag`：AprilTag 标签检测与角点解算（来自 `apriltag_ros`）
  - `/{camera_id}/wechat_qr_node`：WeChatQR 深度学习识别与 6D 位姿解算
- **辅助独立进程**（Python 节点）：
  - `/{camera_id}/apriltag_pose_reader`：TF 监听与位姿/变换格式转换转发
  - `/{camera_id}/keyence_sr_node`：Keyence TCP 长连接驱动与自动重连
  - `/{camera_id}/vision_status_aggregator`：诊断指标汇总与评级

### 2.2 本地源码调试模式

单模块开发调试时，可在宿主机直接编译源码并手动启动节点，调试前请务必确认已停止 Docker 容器（`docker stop basler_camera`），避免物理相机与网络端口冲突。

## 3. 对外标准接口一览（机器人与 MES 对接契约）

### 3.1 视觉感知与结果输出话题

| 话题名称 | 消息类型 | QoS 策略 | 业务说明 |
|---|---|---|---|
| `/{camera_id}/pylon_ros2_camera_node/image_raw` | `sensor_msgs/msg/Image` | `BEST_EFFORT`, Depth 1 | 相机原始图像流 |
| `/{camera_id}/pylon_ros2_camera_node/camera_info` | `sensor_msgs/msg/CameraInfo` | `BEST_EFFORT`, Depth 1 | 相机内参与畸变标定数据 |
| `/{camera_id}/qr/decoded_info` | `std_msgs/msg/String` | `RELIABLE` | 二维码解码文本（带去重抑制） |
| `/{camera_id}/qr/qr_pose` | `geometry_msgs/msg/PoseStamped` | `RELIABLE` | 二维码 6D 空间位姿（需相机具备有效内参标定） |
| `/{camera_id}/apriltag/pose` | `geometry_msgs/msg/PoseStamped` | `RELIABLE` | AprilTag 在相机坐标系下的 6D 位姿 |
| `/{camera_id}/apriltag/transform` | `geometry_msgs/msg/TransformStamped` | `RELIABLE` | AprilTag 坐标系变换数据 |
| `/{camera_id}/scanner/barcode` | `std_msgs/msg/String` | `RELIABLE` | Keyence 扫码器解码内容 |
| `/{camera_id}/vision/status` | `pylon_ros2_camera_interfaces/msg/VisionStatus` | `RELIABLE` | 流水线整体健康度与关键指标 |

### 3.2 触发与控制服务

| 服务名称 | 服务类型 | 业务说明 |
|---|---|---|
| `/{camera_id}/scanner/trigger` | `std_srvs/srv/Trigger` | 机器人动作到位后，发送 `LON\r` 指令主动触发单次扫码 |
| `/{camera_id}/pylon_ros2_camera_node/set_exposure` | `pylon_ros2_camera_interfaces/srv/SetExposure` | 动态调整相机曝光时间（微秒） |
| `/{camera_id}/pylon_ros2_camera_node/set_gain` | `pylon_ros2_camera_interfaces/srv/SetGain` | 动态调整相机模拟/数字增益 |

### 3.3 数据流模式说明

1. **二维码与 AprilTag（持续检测流）**：
   - 节点持续接收相机帧进行推理与位姿解算。二维码节点内置 `min_detect_interval_s`（默认 $0.2\text{ s}$）与 `deduplicate_window_s`（默认 $0.5\text{ s}$）抑制重复推送。
2. **Keyence 扫码器（请求-响应单次触发）**：
   - 典型工作流程：机器人运动到位 $\to$ 调用 `/{camera_id}/scanner/trigger` $\to$ 等待 `/{camera_id}/scanner/barcode` 输出条码 $\to$ 执行下一步装配/入库逻辑。

## 6. 机器人端调用参考代码

### 6.1 Python：订阅二维码文本与 6D 位姿

```python
import rclpy
from rclpy.node import Node
from std_msgs.msg import String
from geometry_msgs.msg import PoseStamped

class VisionSubscriber(Node):
    def __init__(self):
        super().__init__('vision_subscriber')
        self.qr_sub = self.create_subscription(
            String,
            '/my_camera/qr/decoded_info',
            self.qr_callback,
            10
        )
        self.pose_sub = self.create_subscription(
            PoseStamped,
            '/my_camera/qr/qr_pose',
            self.pose_callback,
            10
        )

    def qr_callback(self, msg: String):
        self.get_logger().info(f'收到二维码内容: {msg.data}')

    def pose_callback(self, msg: PoseStamped):
        pos = msg.pose.position
        self.get_logger().info(f'二维码 6D 位姿: x={pos.x:.3f}, y={pos.y:.3f}, z={pos.z:.3f}')

def main():
    rclpy.init()
    node = VisionSubscriber()
    rclpy.spin(node)
    node.destroy_node()
    rclpy.shutdown()

if __name__ == '__main__':
    main()
```

### 6.2 Python：主动触发 Keyence 扫码

```python
import rclpy
from rclpy.node import Node
from std_srvs.srv import Trigger

class KeyenceClient(Node):
    def __init__(self):
        super().__init__('keyence_client')
        self.client = self.create_client(Trigger, '/my_camera/scanner/trigger')

    def trigger_scan(self, timeout_sec=3.0) -> bool:
        if not self.client.wait_for_service(timeout_sec=timeout_sec):
            self.get_logger().error('扫码服务不可用!')
            return False
        
        request = Trigger.Request()
        future = self.client.call_async(request)
        rclpy.spin_until_future_complete(self, future, timeout_sec=timeout_sec)
        
        if future.result() is not None:
            res = future.result()
            self.get_logger().info(f'扫码响应: success={res.success}, msg={res.message}')
            return res.success
        else:
            self.get_logger().error('调用超时或失败')
            return False

def main():
    rclpy.init()
    node = KeyenceClient()
    node.trigger_scan()
    node.destroy_node()
    rclpy.shutdown()

if __name__ == '__main__':
    main()
```

### 6.3 C++：订阅 AprilTag 位姿与坐标系

```cpp
#include <memory>
#include "rclcpp/rclcpp.hpp"
#include "geometry_msgs/msg/pose_stamped.hpp"

class AprilTagListener : public rclcpp::Node {
public:
  AprilTagListener() : Node("apriltag_listener") {
    sub_ = this->create_subscription<geometry_msgs::msg::PoseStamped>(
      "/my_camera/apriltag/pose", 10,
      [this](const geometry_msgs::msg::PoseStamped::SharedPtr msg) {
        RCLCPP_INFO(this->get_logger(),
                    "AprilTag 位姿: Frame=%s, Pos=[%.3f, %.3f, %.3f]",
                    msg->header.frame_id.c_str(),
                    msg->pose.position.x,
                    msg->pose.position.y,
                    msg->pose.position.z);
      });
  }

private:
  rclcpp::Subscription<geometry_msgs::msg::PoseStamped>::SharedPtr sub_;
};

int main(int argc, char ** argv) {
  rclcpp::init(argc, argv);
  rclcpp::spin(std::make_shared<TagPoseListener>());
  rclcpp::shutdown();
  return 0;
}
```

## 8. 常见问题排查速查

1. **容器状态显示 `unhealthy`**：
   - 查看容器日志：`docker logs --tail 200 basler_camera`。
   - 手动执行健康检查探针：`docker exec basler_camera /opt/ros2_ws/deploy/basler_camera/healthcheck.sh`。
   - 确认相机 IP 与扫码器 IP 是否连通、是否有其他进程占用相机。
2. **宿主机看不到视觉话题**：
   - 确认宿主机终端已执行 `export ROS_DOMAIN_ID=0`。
   - 确认 Docker 容器配置了 `network_mode: host`。
3. **AprilTag 无法输出位姿**：
   - 确认相机内参已正确加载，且视野内标签为 `36h11` 系列（默认 ID $0 \sim 11$）。
   - 查看原始检测话题：`ros2 topic echo /my_camera/detections --once`。
4. **扫码器触发无响应**：
   - 检查工控机与扫码器网口直连 IP 配置，确认 `telnet 172.31.0.91 9004` 连通性。
