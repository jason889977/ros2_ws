版本: 2026-08-07

## 1. 安装目标

本清单用于统一系统集成环境，避免因组件版本不一致导致:
- 节点可启动但图谱不连通
- 图像链路中断
- 二维码节点无法稳定识别

## 3. 必须安装的软件与组件

### 3.1 系统基础组件（必须）

```bash
sudo apt-get update
sudo apt-get install -y \
  build-essential \
  cmake \
  git \
  wget \
  curl \
  libusb-1.0-0-dev \
  python3-opencv \
  python3-pip \
  python3-colcon-common-extensions
```

用途:
- 编译 C++ 包
- 提供 OpenCV 与 USB 底层支持
- 提供 colcon 构建能力

### 3.2 ROS2 运行时组件（必须）

先加载 ROS 环境:

```bash
source /opt/ros/humble/setup.bash
```

安装:

```bash
sudo apt-get install -y \
  ros-humble-image-transport \
  ros-humble-camera-info-manager \
  ros-humble-cv-bridge \
  ros-humble-launch \
  ros-humble-launch-ros
```

用途:
- 图像 topic 传输
- 相机内参管理
- ROS 图像与 OpenCV 的桥接
- launch 系统运行

### 3.3 Basler pylon SDK（必须）

推荐冻结版本:
- pylon 8.0.0（与当前仓库脚本一致）

说明:
- install_basler_driver.sh 采用 pylon 8.0.0 自动下载路径
- install_dependencies.sh 中历史提示包含 25.06 手动路径
- 为避免歧义，交接基线以 8.0.0 为准

安装方式 A（推荐，自动化）:

```bash
cd /home/ubuntu/ros2_ws
chmod +x install_basler_driver.sh
./install_basler_driver.sh
```

安装方式 B（已有 pylon 环境）:
- 保证系统已有 /opt/pylon
- 能执行 source /opt/pylon/bin/pylon-setup-env.sh pylon

### 3.4 工作区构建（必须）

```bash
cd /home/ubuntu/ros2_ws
source /opt/ros/humble/setup.bash
colcon build --symlink-install --cmake-args -DCMAKE_BUILD_TYPE=Release
source install/setup.bash
```

用途:
- 生成可执行 launch 与节点
- 安装 Python/C++ 包到 install 空间

## 6. 常见安装错误与处理

1. 错误: source setup.bash 提示文件不存在
- 原因: 在 ros2_ws 根目录误用了 setup.bash
- 正确: source install/setup.bash

2. 错误: decoded_info 无发布
- 先查 image_raw 发布者数量
- 若 Publisher count=0，先恢复相机节点

3. 错误: 出现 3774873620 或 grabbed 不完整
- 进入网络与稳定性排查
- 参考 docs/10-Network-Tuning-Playbook.md
