# 组件与依赖安装详单（必须项）

版本: 2026-08-16
适用环境: Ubuntu 22.04 + ROS2 Humble + Basler pylon
工作区: /home/ubuntu/ros2_ws

## 1. 安装目标

本清单用于统一系统集成环境，避免因组件版本不一致导致:
- 节点可启动但图谱不连通
- 图像链路中断
- 二维码节点无法稳定识别

## 2. 已验证环境版本（本机证据）

1. 操作系统
- Ubuntu 22.04 LTS x86_64

2. Python 与 OpenCV
- Python 3.10.x
- NumPy 1.26.4
- opencv-contrib-python-headless 4.8.1.78
- 不安装其他 pip OpenCV wheel，避免 `cv2` 被覆盖

3. ROS2 发行版与关键包
- ROS2: Humble
- ros-humble-desktop（版本以 Jammy 源为准）
- 相机图像: image-transport, image-geometry, camera-info-manager, cv-bridge
- 标定显示: camera-calibration, rviz2, rqt-image-view
- 检测诊断: apriltag-ros, apriltag-msgs, pcl-ros, diagnostic-updater

4. 构建工具链
- cmake: Jammy 官方版本，最低 3.22
- build-essential: Jammy 官方版本
- python3-colcon-common-extensions: 0.3.0-100
- libusb-1.0-0-dev: Jammy 官方版本

5. Basler SDK
- pylon: 8.0.0.16021-deb0
- dpkg 包名: pylon

## 3. 必须安装的软件与组件

### 3.1 系统基础组件（必须）

```bash
cd /home/ubuntu/ros2_ws
bash install_dependencies.sh
```

运行前必须按 ROS 官方文档配置 Humble apt 软件源。该脚本会安装系统工具、ROS 2 Desktop、完整 ROS 直接依赖、冻结的 Python 图像环境、pylon SDK，并构建 6 个工作区包。脚本需要 sudo 权限和网络连接。

### 3.2 ROS2 运行时组件（必须）

先加载 ROS 环境:

```bash
source /opt/ros/humble/setup.bash
```

关键包必须至少包含:

```bash
sudo apt-get install -y \
  ros-humble-desktop \
  ros-humble-image-transport \
  ros-humble-image-geometry \
  ros-humble-camera-info-manager \
  ros-humble-cv-bridge \
  ros-humble-camera-calibration \
  ros-humble-diagnostic-updater \
  ros-humble-pcl-ros \
  ros-humble-apriltag-ros \
  ros-humble-apriltag-msgs \
  ros-humble-launch \
  ros-humble-launch-ros \
  ros-humble-rviz2 \
  ros-humble-rqt-image-view
```

用途:
- 图像 topic 传输
- 相机内参管理
- ROS 图像与 OpenCV 的桥接
- launch 系统运行

### 3.3 Basler pylon SDK（必须）

推荐冻结版本:
- pylon 8.0.0（与当前仓库脚本一致）

说明:
- install_basler_driver.sh 采用 pylon 8.0.0 自动下载路径
- install_dependencies.sh 中历史提示包含 25.06 手动路径
- 为避免歧义，交接基线以 8.0.0 为准

安装方式 A（推荐，完整自动化）:

```bash
cd /home/ubuntu/ros2_ws
bash install_dependencies.sh
```

安装方式 B（只安装 pylon 并构建）:
- `bash install_basler_driver.sh`

已有 pylon 环境必须满足:
- 保证系统已有 /opt/pylon
- `dpkg-query -W pylon` 显示 8.0.0.x
- `/opt/pylon/bin/pylon-setup-env.sh` 存在
- 不要使用 sudo source，也不要在项目外持久化错误的 PYLON_ROOT

### 3.4 工作区构建（必须）

```bash
cd /home/ubuntu/ros2_ws
source /opt/ros/humble/setup.bash
colcon build --symlink-install --cmake-args -DCMAKE_BUILD_TYPE=Release
source install/setup.bash
```

用途:
- 生成可执行 launch 与节点
- 安装 Python/C++ 包到 install 空间

终端3（验证）:

```bash

source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 node list
ros2 topic info -v /bridge/image_raw
ros2 topic echo /wechat_qr_node/decoded_info --once
```

通过标准:
- image_raw 的 Publisher count >= 1
- image_raw 的 Subscription count >= 1
- 图像规格为 Mono8、1294x970、2x2 binning
- 驱动 `Image publish FPS` 或 `/diagnostics` 发布计数约为 14-15 FPS
- decoded_info 在二维码可见时可输出 data

## 6. 常见安装错误与处理

1. 错误: source setup.bash 提示文件不存在
- 原因: 在 ros2_ws 根目录误用了 setup.bash
- 正确: source install/setup.bash

2. 错误: decoded_info 无发布
- 先查 image_raw 发布者数量
- 若 Publisher count=0，先恢复相机节点

3. 错误: 出现 3774873620 或 grabbed 不完整
- 保持 mtu_size=1500，检查网线、交换机、网卡同网段设置
- 确认容器健康、实际 profile 为 2x2 binning，并完成桥接话题验收
