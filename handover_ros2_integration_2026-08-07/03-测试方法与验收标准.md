## 3. 公共守门项

以下守门项适用于二维码与 AprilTag 两条链路:

- 相机节点可用
- image_raw 可持续发布
- 图像编码与分辨率为 Mono8、2590x1942
- 驱动 `Image publish FPS` 或 `/diagnostics` 发布计数约为 14-15 FPS
- 单独记录 `ros2 topic hz` 的订阅端到达率，不要求其等于驱动发布计数
- 关键错误码无重复爆发（3774873620 / incompletely grabbed / Grab was not successful）

关键错误码扫描命令:

```bash
latest=$(ls -1t /home/ubuntu/.ros/log/pylon_ros2_camera_wrapper_*.log | head -n 1)
grep -E "3774873620|incompletely grabbed|Grab was not successful" -i "$latest" || true
```
