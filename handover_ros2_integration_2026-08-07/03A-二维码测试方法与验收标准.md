# 二维码测试方法与验收标准

## 1. 测试目标

验证相机与二维码链路满足可发布运行条件:
- 图谱连通
- 消息可达
- 短时稳定

## 3. 测试项 A: ROS 图谱连通

命令:

```bash
cd /home/ubuntu/ros2_ws
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 node list
ros2 topic info -v /my_camera/pylon_ros2_camera_node/image_raw
```

通过判据:
- 存在节点 /my_camera/pylon_ros2_camera_node
- 存在节点 /wechat_qr_node
- image_raw: Publisher count >= 1
- image_raw: Subscription count >= 1

不通过判据:
- Publisher count = 0 或 /wechat_qr_node 不存在

## 4. 测试项 B: 识别结果可达

命令:

```bash
cd /home/ubuntu/ros2_ws
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 topic echo /wechat_qr_node/decoded_info --once
```

通过判据:
- 在二维码进入视野后，返回一条 data 字段内容

不通过判据:
- 长时间无输出，或提示 topic 未发布

## 5. 测试项 C: 帧率与连续性观察

命令:

```bash
cd /home/ubuntu/ros2_ws
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 topic hz /my_camera/pylon_ros2_camera_node/image_raw
```

通过判据:
- 观测周期内无明显中断
- 与现场基线预期一致

说明:
- VM 场景帧率波动可接受，优先看连续性与稳定性

## 6. 测试项 D: 关键错误码守门

命令:

```bash
latest=$(ls -1t /home/ubuntu/.ros/log/pylon_ros2_camera_wrapper_*.log | head -n 1)
grep -E "3774873620|incompletely grabbed|Grab was not successful" -i "$latest" || true
```

通过判据:
- 无重复爆发式关键错误

不通过判据:
- 出现持续或重复关键错误，需触发回滚或网络排障
