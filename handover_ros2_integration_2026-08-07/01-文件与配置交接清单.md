# 文件与配置交接清单

## 1. 相机配置文件

1. src/pylon_ros2_camera_wrapper/config/aca2500_106611_18.tuned_v3.yaml
- 用途: 当前冻结发布基线
- 关键参数: frame_rate 8.0, grab_timeout 1500, mtu_size 1500, inter_pkg_delay 1000, binning_x 2, binning_y 2
- 交接动作: 作为默认运行配置，不随意改动

2. src/pylon_ros2_camera_wrapper/config/aca2500_106611_18.tuned.yaml
- 用途: 回滚配置
- 交接动作: 仅在 v3 出现稳定性回归时切回

3. src/pylon_ros2_camera_wrapper/config/aca2500_106611_18.tuned_v2.yaml
- 用途: 历史折中版本
- 交接动作: 仅作参考，不作为默认生产参数

## 2. 启动文件

1. src/pylon_ros2_camera_wrapper/launch/pylon_ros2_camera.launch.py
- 用途: Basler 相机主启动入口
- 重点参数: config_file, camera_id
- 交接动作: 保证 config_file 指向 v3 配置

2. src/qrcode_detector/launch/qrcode_detector.launch.py
- 用途: 二维码识别主启动入口
- 重点参数: image_topic, prefer_wechat_qr, model_dir
- 交接动作:
  - 默认保持 prefer_wechat_qr=false
  - image_topic 对齐为 /my_camera/pylon_ros2_camera_node/image_raw

## 3. 二维码核心逻辑

1. src/qrcode_detector/qrcode_detector/qrcode_node.py
- 用途: 图像解码并发布 decoded_info
- 关键点:
  - 默认稳定后端: OpenCV QRCodeDetector
  - 可选 WeChatQR 模型路径
  - 发布话题: /wechat_qr_node/decoded_info
- 交接动作: 不改核心逻辑，只在必要时调整参数

## 4. 自动化与安装脚本

1. scripts/deploy_and_run_camera_qr.sh
- 用途: 一键部署与启动参考
- 交接动作: 作为现场快速执行脚本参考

2. install_basler_driver.sh
- 用途: Basler 驱动安装与构建
- 交接动作: 新机器首次部署使用

3. install_dependencies.sh

- 交接动作: 新机器首次部署使用

## 6. 误配高发点

1. 在错误目录 source setup 文件
- 正确: source /opt/ros/humble/setup.bash + source install/setup.bash

2. 只启动二维码节点，未启动相机
- 现象: image_raw Publisher count 为 0, decoded_info 无输出

3. image_topic 不一致
- 现象: 节点在跑但订阅不到图像

4. 误开 WeChatQR 模型路径
- 建议: 默认使用 prefer_wechat_qr=false，先保证稳定可用
