# 接口参考

以下路径以 `camera_id=my_camera` 为例。更换相机 ID 时替换首段命名空间。

## 1. 主要 ROS 话题

| 话题 | 类型 | 方向/用途 |
| ------ | ------ | ----------- |
| `/my_camera/pylon_ros2_camera_node/image_raw` | `sensor_msgs/msg/Image` | 相机原始图像 |
| `/my_camera/pylon_ros2_camera_node/image_rect` | `sensor_msgs/msg/Image` | 图像处理链使用的校正图像 |
| `/my_camera/pylon_ros2_camera_node/camera_info` | `sensor_msgs/msg/CameraInfo` | 相机内参 |
| `/my_camera/pylon_ros2_camera_node/current_params` | `pylon_ros2_camera_interfaces/msg/CurrentParams` | 当前相机参数 |
| `/my_camera/pylon_ros2_camera_node/status` | `pylon_ros2_camera_interfaces/msg/ComponentStatus` | 相机组件状态 |
| `/my_camera/detections` | `apriltag_msgs/msg/AprilTagDetectionArray` | AprilTag 检测结果 |
| `/my_camera/apriltag/pose` | `geometry_msgs/msg/PoseStamped` | 标签位姿 |
| `/my_camera/apriltag/transform` | `geometry_msgs/msg/TransformStamped` | 标签变换 |
| `/my_camera/scanner/barcode` | `std_msgs/msg/String` | Keyence 扫码结果 |
| `/my_camera/diagnostics` | `diagnostic_msgs/msg/DiagnosticArray` | 流水线组件诊断 |
| `/my_camera/vision/status` | `pylon_ros2_camera_interfaces/msg/VisionStatus` | 聚合健康和扫码指标 |

快速查询：

```bash
ros2 topic list -t | grep '^/my_camera/'
ros2 topic echo /my_camera/vision/status --once
ros2 topic hz /my_camera/pylon_ros2_camera_node/image_raw
```

## 2. Keyence 服务

触发一次扫码：

```bash
ros2 service call /my_camera/scanner/trigger \
  std_srvs/srv/Trigger '{}'
```

成功响应的 `message` 是扫码文本。无读码、协议错误、超时或断线返回 `success=false`；后台定时器负责重连。

## 3. 相机控制服务

常用端点：

| 服务 | 类型 |
| ------ | ------ |
| `/my_camera/pylon_ros2_camera_node/set_exposure` | `pylon_ros2_camera_interfaces/srv/SetExposure` |
| `/my_camera/pylon_ros2_camera_node/set_gain` | `pylon_ros2_camera_interfaces/srv/SetGain` |
| `/my_camera/pylon_ros2_camera_node/set_gamma` | `pylon_ros2_camera_interfaces/srv/SetGamma` |
| `/my_camera/pylon_ros2_camera_node/set_brightness` | `pylon_ros2_camera_interfaces/srv/SetBrightness` |
| `/my_camera/pylon_ros2_camera_node/set_binning` | `pylon_ros2_camera_interfaces/srv/SetBinning` |
| `/my_camera/pylon_ros2_camera_node/set_roi` | `pylon_ros2_camera_interfaces/srv/SetROI` |
| `/my_camera/pylon_ros2_camera_node/set_sleeping` | `pylon_ros2_camera_interfaces/srv/SetSleeping` |

示例：

```bash
ros2 service call \
  /my_camera/pylon_ros2_camera_node/set_exposure \
  pylon_ros2_camera_interfaces/srv/SetExposure \
  '{target_exposure: 15000.0}'
```

驱动还提供统计、chunk、触发、用户集、白平衡、PGI、PTP 等机型相关服务。运行时以节点实际暴露列表为准：

```bash
ros2 service list -t | grep '/my_camera/pylon_ros2_camera_node/'
```

## 4. 相机 Action

接口包定义：

- `pylon_ros2_camera_interfaces/action/GrabImages`；
- `pylon_ros2_camera_interfaces/action/GrabBlazeData`。

可用性取决于相机类型和驱动构建。查询实际端点：

```bash
ros2 action list -t | grep pylon_ros2_camera_node
```

## 5. 标定接口

| 名称 | 类型 | 启动方式 |
| ------ | ------ | ------ |
| `/calibrate_camera` | `apriltag_pose_reader_interfaces/action/CalibrateCamera` | Dashboard 自动启动，也可手动 `ros2 run aprilgrid_calibration aprilgrid_calibration_server` |
| `/{node_namespace}/handeye_static_tf_broadcaster/reload_calibration` | `apriltag_pose_reader_interfaces/srv/ReloadCalibration` | 由流水线启动静态发布器 |

统一视觉流水线不会自动启动内参标定 Action server；内参标定和手眼标定均通过 Web Dashboard 四步向导完成。详见 [标定与 TF](06-标定与TF.md)。

## 6. VisionStatus 字段

`VisionStatus` 包含：

- `camera_id`、`overall_level`、`summary`；
- 活跃、警告和错误组件数量；
- 组件名称、消息和值键值列表；
- 总扫码数、Keyence 数；
- 每分钟扫码率、最后扫码时间和漏扫持续时间。

等级常量：`OK=0`、`WARN=1`、`ERROR=2`、`STALE=3`。

| GET | `/api/camera/image` | 最新 JPEG 快照 |
| GET | `/api/camera/stream` | MJPEG 流，最多 4 个并发流 |
| GET | `/api/events?limit=50` | 当前及轮转事件日志 |
| GET | `/api/archive` | PNG 归档清单 |
| GET | `/api/archive/{filename}` | 下载归档图像 |

```text

```

## 8. HTTP 安全边界

当前实现：

- uvicorn 只监听 `127.0.0.1`；
- 不配置 CORS；
- 带 `Origin` 的 POST/PUT/DELETE/PATCH 必须与 Host 同源；
- HTTP 请求体上限为 1 MiB；
- API 本身没有用户登录机制。

因此不要把端口直接暴露到不可信网络。需要远程控制时应增加认证代理和访问控制。
