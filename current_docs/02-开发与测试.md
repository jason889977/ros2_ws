# 开发与测试

## 1. 环境要求

推荐环境：

- Ubuntu 22.04；
- ROS 2 Humble；
- Python 3.10；
- 支持 C++17 的编译器；
- OpenCV、cv_bridge、diagnostic_updater、apriltag_ros；
- 构建相机组件时需要 Basler pylon SDK。

每个终端先加载环境：

```bash
cd /home/ubuntu/ros2_ws
source /opt/ros/humble/setup.bash
```

## 2. 构建

### 完整依赖闭包

```bash
colcon build --symlink-install \
  --packages-up-to industrial_vision_bringup \
  --event-handlers console_direct+
source install/setup.bash
```

该命令会包含统一流水线需要的工作区包。相机组件需要 pylon SDK 可被 CMake 找到。

### 无 pylon SDK 的开发构建

```bash
colcon build --symlink-install \
  --packages-select \
    apriltag_pose_reader_interfaces \
    pylon_ros2_camera_interfaces \
    vision_core vision_nodes vision_dashboard \
    aprilgrid_calibration handeye_calibration \
    apriltag_pose_reader keyence_sr_wrapper
source install/setup.bash
```

  这条路径用于算法和 Dashboard 开发，不构建 Basler 相机实现。`industrial_vision_bringup`
  依赖相机 component 和 wrapper，因此也不包含在无 SDK 构建中。

  `vision_dashboard` 现在通过 `vision_core` 直接调用手眼求解器完成 Web 向导；仍然保留
  `handeye_calibration` 包以便运行离线 CLI 工具与 `handeye_static_tf_broadcaster`。

### 单包重建

```bash
colcon build --symlink-install --packages-select vision_core
source install/setup.bash
```

修改接口包后，优先使用 `--packages-up-to` 或同时重建依赖它的包。

## 3. Python 测试

测试目录由根目录 `pyproject.toml` 管理：

```bash
source /opt/ros/humble/setup.bash
source install/setup.bash
export PYTEST_DISABLE_PLUGIN_AUTOLOAD=1
python3 -m pytest -q
```

需要覆盖率时：

```bash
python3 -m pytest -p pytest_cov \
  --cov=vision_core \
  --cov=vision_nodes \
  --cov=vision_dashboard \
  --cov=keyence_sr_wrapper \
  --cov-report=term
```

`vision_dashboard` 下的测试覆盖两条标定向导：

- `calibration_routes.py` — AprilGrid 内参标定的会话、采集、Action 提交与应用；
- `handeye_routes.py` — 手眼标定的手动 6 维位姿录入、多样性门禁、`vision_core.solve_hand_eye`
  后台求解、YAML 落盘与 TF 重载服务调用。

当前基线收集为 181 项 pytest。测试数量会随代码变化，验收时应以当前命令输出为准。

## 4. CTest 与 ament lint

```bash
source /opt/ros/humble/setup.bash
source install/setup.bash
colcon test --packages-select \
  pylon_ros2_camera_component \
  --event-handlers console_cohesion+ \
  --return-code-on-test-failure
colcon test-result --verbose
```

没有 pylon SDK 时只测试 Python 包：

```bash
colcon test --packages-select vision_core vision_nodes vision_dashboard \
  --event-handlers console_cohesion+ \
  --return-code-on-test-failure
colcon test-result --verbose
```

## 5. 静态检查

仓库根目录 `.pre-commit-config.yaml` 定义本地 hook：

- Python：flake8，最大行长 100；
- Shell：`bash -n`；
- JavaScript：`node --check`；
- YAML：PyYAML 解析。

运行方式：

```bash
python3 -m pip install --user pre-commit
pre-commit run --all-files
```

也可以直接执行 CI 使用的基础检查：

```bash
bash -n deploy/basler_camera/entrypoint.sh \
  deploy/basler_camera/healthcheck.sh
python3 -m compileall -q src scripts
find src -name '*.js' -print0 | xargs -0 -r -n1 node --check
cmp -s \
  src/pylon_ros2_camera_wrapper/config/aca2500_106611_18.yaml \
  deploy/basler_camera/config/aca2500_106611_18.yaml
```

## 6. CI 行为

`.github/workflows/build-test.yml` 在以下场景执行：

- push 到 `main`；
- 向 `main` 提交 pull request；
- 每日定时任务。

CI 会：

1. 安装 ROS、OpenCV、Python 和测试依赖；
2. 从候选目录检测 pylon SDK；
3. 根据 SDK 是否可用选择构建包；
4. 检查脚本、Python 和 JavaScript 语法；
5. 运行 pytest 和覆盖率；
6. 运行可用时的 Pylon CTest；
7. 运行 ament lint 并上传覆盖率 XML。
